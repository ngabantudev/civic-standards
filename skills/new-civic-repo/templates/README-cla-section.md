## Licensing your contribution

This project is licensed **AGPL-3.0**. Anyone may use, modify, and host it,
including commercially — but any modified version offered over a network must
publish its source. Nobody takes this private.

Data published by the project is **CC BY-SA 4.0**. Upstream data keeps its own
licenses; see `LICENSE-DATA.md`.

## Contributor License Agreement

First-time contributors sign a short CLA (see `CLA.md`). You keep copyright in
your work — the CLA grants the maintainer a license, including the right to
offer the project under a commercial license alongside AGPL.

Sign by commenting on your first pull request:

```
I have read the CLA and I agree to it. Signed, <your name> <@your-github-handle>
```

This is a one-time step. Ask in an issue if anything about it is unclear.

## Why dual licensing

The AGPL version is permanent and public. The commercial option exists so the
project can fund itself without going closed — a familiar pattern in
public-interest software, and it only works if all copyright can be
relicensed, which is what the CLA preserves.
